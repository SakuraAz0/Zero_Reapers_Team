## 2026-10-31　车2：机械臂控律/底盘调参 + PS2 稳定性（分支 car2）

### 舵机（`USER/servo.h` / `USER/servo.c`）
- **角度配置体系**：每路只填 4 个宏（`OFFSET / MIN_ANGLE / MAX_ANGLE / START_ANGLE`，单位 °），
  `MIN_US/MAX_US/START_US` 自动换算；编译期 `#warning` 自检行程是否越界（低于 500us / 高于 2500us）。
- **角度斜坡**：`slew_toward_target()` 每个主循环 tick 分步逼近目标（0.1us 累加器），无 `HAL_Delay` 阻塞。
- **加减速曲线**（`SERVO_RAMP_*`）：起步/收尾渐变、中间匀速。当前 **9 tick ≈ 90ms**（10ms 节拍）起停。
  调参轨迹：8/10 不明显 → 20/20 太缓 → 12/12 略拖 → 8/6 收尾干脆 → **9/9 折中**。
- **错峰动作**：多个手动输入同时存在时，**只执行优先级最高的一路**：
  `MG995(右摇杆) > SG90下(L1/L2) > SG90上(R1/R2) > 机械爪(□/○)`，避免多舵机同时抢电流。
- **联动限位**：`MG995 ≥ 138°` 时 `SG90(上) ≤ 87°`（防机械干涉）。双向生效：
  设置 CH4 目标时按 MG995 当前角限幅；每 tick 检查，MG995 高位则把 CH4 目标压回 87°。MG995 本身不受反向限制。
- **机械爪**：
  - 两端各留 **5° 安全余量**（`SERVO_GRIP_TRIM_DEG`）：行程 80°，脉宽 **412~1300us**，一键合上 **700us**；
  - **越靠近闭合端越慢**（`SERVO_GRIP_SLOW_*`）：进入最后 25° 线性降速，贴到闭合端只剩 20% 速度；
  - 一键张合端点改为绝对脉宽（不受"两端收进"影响）。
- **速度**（`SERVO_*_DEG_PER_SEC`，步长按 `SERVO_TICK_MS` 自动换算）：

  | 舵机 | 速度 | 实际 |
  |---|---|---|
  | MG995（CH1） | 114°/s | 114.3°/s |
  | SG90(下)（CH2，车2 无） | 126°/s | 126.0°/s |
  | SG90(上)（CH4） | 140°/s | 140.4°/s |
  | 机械爪（CH3） | 190°/s | 189.9°/s |

### 一键动作
- 车2（3 舵机：MG995 + 上面 SG90 + 机械爪）：`SERVO_HAS_SG90_LOW=0`，序列**自动跳过**未装的 CH2。
  - **模式 0（上电默认）**：`L1` = 一键放下、`L2` = 一键摆臂（角度全由 `SERVO_DROP_*` / `SERVO_POSE_*` 宏控制）；
    动作顺序：放下 = MG995 → SG90(上) → 延时 → 张爪；摆臂 = SG90(上) → MG995 → 延时 → 张爪；
  - **模式 1**：只有机械爪一键张合（□ 张开 / ○ 合上）。
  - 序列运行中按 右摇杆 / □ / ○ 可立即中止。
- 车1（4 舵机）：模式 1 的 `L1/L2/R1/R2` 四个一键序列；□/○ 一键张合；模式 0 全点动。

### 底盘（`USER/control.h`）
- **档位**：慢速 10~30%、**中速 30~60%（上电默认）**、快速 60~85%；三档首尾相接。
- **绕后轮**（右摇杆 X）映射到物理可用区间 **600~920**：慢速 60%、中速 78%、快速 92%
  （低于 600 该轮转不动，所以不跟随档位降低）。
- 方向键平移 70%（仍受当前档位上限约束）；全局占空比上限 92%（`CTRL_DUTY_CAP`）。
- **马达软启动 + 加减速曲线**（`MOTOR_SLEW_STEP=26` / `MOTOR_RAMP_*`）：满载约 385ms，
  起步约 80ms 渐加速、收尾约 50ms 渐减速；`Motor_StopAll/BrakeAll` 会清零速度状态。

### PS2 手柄
- **轮询周期 5ms → 10ms（200Hz → 100Hz）**：解决现场"手柄总是掉模式"（红灯→绿灯）——
  廉价 2.4G 接收器跟不上 200Hz 包流。10ms 也是手柄原生帧周期。
- **关闭振动**（`PS2_ENABLE_RUMBLE=0`）：减少对接收器的额外写操作（项目本来也没用振动）。
- **掉模式恢复提速**：
  - 掉出模拟模式**第一帧立即重发配置**（无视限速）；
  - 之后按 `PS2_RECONFIG_INTERVAL_MS=200ms` 限速重试；
  - 连续 `PS2_MODE_ESCALATE_AFTER=3` 次拉不回来 → 升级为 `PS2_Init()` 整包重初始化（防接收器/手柄卡死）；
  - `s_reinit_guard` 防 PS2_Init 内部读包导致的递归。
- 失联保护、安全启动回中校验（4 轴 128±20 持续 200ms 才使能）保持不变。

### 构建/烧录
- 主循环节拍与舵机/马达参数联动：`PS2_READ_PERIOD_MS=10` ↔ `SERVO_TICK_MS=10` ↔ `MOTOR_SLEW_STEP=26`
  （改节拍必须三处同步，否则速度/软启动时间会变）。
- 排查记录：复制出来的工程目录**改名后无法烧录**（`_build_flash/CMakeCache.txt` 仍指向老路径，
  cmake 报 "source does not match"）→ 删除 `_build_flash`、`cmake-build-debug-stm32` 重新构建即可。
- 烧录仍用 `tools\flash.ps1`（ST-LINK hot-plug 模式，3 次重试）。
